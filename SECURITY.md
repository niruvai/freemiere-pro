# Security Policy

## Supported versions

Only the [latest release](https://github.com/niruvai/freemiere-pro/releases/latest) of Freemiere Pro receives security fixes. The app updates itself, so please keep it up to date (menu **Freemiere Pro → Check for Updates…**).

## Reporting a vulnerability

**Please do not report security problems in public issues.**

Report them privately instead:

1. Open the [Security tab](https://github.com/niruvai/freemiere-pro/security) of this repository
2. Click **Report a vulnerability**
3. Describe the problem, how to reproduce it, and which version you use (**Freemiere Pro → About Freemiere Pro**)

You will get a reply within 7 days. Once the problem is fixed, a new release is published and you will be credited if you wish.

## What counts as a security issue

For example:

- A project file or media file that makes the app run code or commands
- The app reading or writing files outside the folders you chose
- A web page or other app being able to read your media through the app's internal `flmedia://` media handler
- The updater installing something that is not an official Freemiere Pro release
